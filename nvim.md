## installation

```
# https://neovim.io/doc/build/#build-prerequisites

sudo apt update && apt get install ninja-build gettext cmake curl build-essential git

1. # required 
mv ~/.config/nvim{,.bak} 
 # optional but recommended 
mv ~/.local/share/nvim{,.bak} 
mv ~/.local/state/nvim{,.bak} 
mv ~/.cache/nvim{,.bak}

2. git clone https://github.com/LazyVim/starter ~/.config/nvim

3. run :LazyHealth after installation.
```
